Why it matters

From messy notes to a clear day.

01

Brain dump

Paste rough notes in English, Russian, or translit and LifePilot turns them into dated priorities.

02

Daily plan

Sorts the day by urgency, impact, money risk, document deadlines, and health tasks.

03

Risk radar

Shows overdue tasks, money exposure, document pressure, and health reminders before they become problems.

04

Backup ready

Export and import JSON backups so early users can trust the beta with real data.

Beta install

Android APK, iPhone web app.

Android testers can install the APK. iPhone testers should open the web app link in Safari and use Add to Home Screen.

Download release APK
Android

Install APK

Download `app-release.apk`, allow install from browser/files if Android asks, then open LifePilot.

iPhone

Use Safari

Open the web app link, tap Share, choose Add to Home Screen, then launch LifePilot from the icon.
