# LifePilot Beta

Public beta distribution for LifePilot.

## Test links

- Web/PWA: https://phototalj-lab.github.io/lifepilot-beta/
- Android APK: https://phototalj-lab.github.io/lifepilot-beta/app-release.apk
- Privacy policy: https://phototalj-lab.github.io/lifepilot-beta/privacy.html

## Android

Download `app-release.apk` and install it on Android.

## iPhone

Open the Web/PWA link in Safari, tap Share, then Add to Home Screen.
